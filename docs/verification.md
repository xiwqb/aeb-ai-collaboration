# 怎样判断AI输出是否可靠

| 要核验的问题 | 证据与计算 | 能支持的判断 | 不能外推的结论 |
|---|---|---|---|
| 单位是否正确 | 原生Vx为km/h、Ax为g；换算并检验数量级 | 当前接口约定成立 | 其他模型一定采用相同单位 |
| 车型参数是否生效 | 模型快照、原始展开参数哈希、1674 kg回读摘要 | 本组为X3参数配置 | 完成X3实车标定或X5实验 |
| 压力输入是否有作用 | Kp从1.4改为0，保持触发及断油门 | 压力前向通路能改变制动响应 | 所有反馈和整个AEB逻辑都正确 |
| 释放条件是否影响结果 | 同触发条件，仅释放阈值−1改为4.9 | 本次停车中保持减少反复切换 | 优于所有TTC控制器 |
| 通道是否相互解释 | ∫Vx/3.6 dt 与Xo变化的差小于0.0006 m | 当前记录运动学一致 | 已由独立实车测量验证 |
| 原生与Simulink输出是否对应 | 依据观察到的一步采样关系对齐，残差小于10⁻⁵ | 接口与数据处理对应 | 独立物理模型验证 |
| 同配置是否可复现 | 比较690个原生通道和Simulink逐点输出 | 687个非计时通道及全部Simulink输出完全相同 | 有统计意义的多次随机试验 |

原生采样周期0.0001 s，六组各100001点。观察到的采样关系为：Vx和Xo同索引对应；`native_Ax[k]=simulink_Ax[k+1]`；`native_pressure[k+1]=simulink_pressure[k]`。只在零时移下比较会把时序关系误当作幅值误差。

原始车辆求解记录含轮胎、悬架及制动表外推警告；核验报告保留警告文本。停车后仍存在小幅速度和加速度残余，论文采用的停车指标仅是首次Vx≤0.5 km/h。

`scripts/verify_evidence.py`从公开数据重算：最小坐标间距、触发/停车时刻、切换次数、压力峰值、速度积分误差、通道对齐残差以及完整690通道重复性。`results/verification/original_audit.json`是原有核验报告的公开副本，移除了操作时间字段，保留结果和警告。
